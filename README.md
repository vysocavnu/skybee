# 🐝 Skybee

Відкритий клієнт для [Bluesky](https://bsky.app). Веб-версія: **https://vysocavnu.github.io/skybee**

## Що вміє
- Вхід за коротким ніком (`@lejk309`) або email; пароль застосунку чи основний пароль (з кодом із пошти); підтримка Eurosky та власних серверів
- Кілька акаунтів із швидким перемиканням
- Стрічка «Підписки» + закріплені фіди та списки вкладками
- Пости: текст з посиланнями/@згадками/#хештегами, до 4 фото з ALT, відео або GIF, картки посилань, вибір мови
- Налаштування «хто може відповідати» — під час публікації та для вже опублікованих постів
- Приховані слова, фрази й теги
- Відповіді, поширення, цитати, вподобання, закладки, переклад, копіювання, видалення
- Гілки обговорень, списки хто вподобав / поширив / процитував
- Профілі: банер, біо, вкладки (пости, відповіді, медіа, відео, вподобання, фіди, списки), редагування свого профілю
- Стежити / приховати / заблокувати / поскаржитись
- Сповіщення (згруповані), окрема вкладка згадок, лічильник непрочитаних
- Пошук постів (топ / нові), людей, фідів; тренди й рекомендації
- Фіди: пошук, збереження, закріплення на головній, зміна порядку; набір фідів за замовчуванням
- Налаштування: стрічка «Підписки», порядок відповідей, хто може писати в чат, розмір тексту, обов'язковий ALT
- Особисті повідомлення (чати)
- Відео (HLS), розмиття контенту 18+, теми: темна / сутінки / світла
- Встановлення як застосунку (PWA), системні сповіщення, поки Skybee відкритий
- Оформлення профілю для користувачів Skybee: статус у бульбашці, трек під біо, колір сторінки, іграшка на банері
- Гарячі клавіші: `n` — новий пост, `/` — пошук

## Ще немає
Push-сповіщення при закритому застосунку, пошук GIF, налаштування цитування.

## Запуск локально
```
python -m http.server
```
і відкрити http://localhost:8000

## Версія для Windows
Інсталятор `Skybee-…-setup.exe` і переносний `Skybee-…-portable.exe` лежать у [релізах](https://github.com/vysocavnu/skybee/releases).
Це оболонка на Electron (`desktop/`) довкола тієї самої вебверсії: має власний рушій, Edge чи WebView2 не потрібні.

Зібрати самому (потрібен Node):
```
cd desktop
npm install
npm start        # запустити
npm run dist     # зібрати EXE у desktop/dist
```
Новий реліз: змінити версію в `desktop/package.json`, потім `git tag v0.1.0 && git push origin v0.1.0`.
