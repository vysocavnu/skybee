# Skybee 🐝 — інструкції для Claude

Skybee — відкритий клієнт для Bluesky (AT Protocol). Автор: vysocavnu.
Спілкуйся українською. Відповідай коротко й по суті.

## Стан проєкту
- Зараз це **веб-версія** (vanilla JS, ES-модулі, без збірки і без залежностей).
- Хостинг: GitHub Pages з гілки `main`, корінь репозиторію → https://vysocavnu.github.io/skybee
  Кожен push у `main` автоматично оновлює сайт.
- Є **десктопна версія для Windows на Electron** (`desktop/`): лише інсталятор NSIS (переносну версію автор попросив прибрати).
  Саме Electron, а не Tauri: Tauri на Windows потребує WebView2 (Edge), а в автора Edge заблокований — застосунок має нести власний рушій.
  Збирає GitHub Actions (`.github/workflows/desktop.yml`): тег `vX.Y.Z` → реліз; будь-які зміни застосунку (веб чи `desktop/`) або ручний запуск → артефакти.
  Інтерфейс у десктопі **оновлюється сам**: під час запуску оболонка тихо завантажує сайт із GitHub Pages у `userData/web-cache`
  і з наступного запуску показує його, якщо він новіший за збірку. Новий EXE потрібен лише при зміні `desktop/main.js` чи Electron.
  Версія — у `desktop/package.json`. Далі за планом: Linux, macOS, потім Android, iOS.

## Структура
- `index.html` — оболонка, підключає `css/style.css` і `js/app.js`
- `sw.js`, `manifest.webmanifest`, `icons/` — PWA. Service worker працює за принципом «спершу мережа» (кеш лише для офлайну)
  і обробляє кліки по системних сповіщеннях. Новий файл оболонки треба дописати в список `SHELL` у `sw.js`
- `js/api.js` — сесії кількох акаунтів (`skybee.accounts`), threadgate, postgate (заборона й від'єднання цитат), приховані відповіді, списки, фільтри контенту, паролі застосунків, приховані слова, завантаження відео через video.bsky.app, XRPC-запити з авто-оновленням токена, визначення PDS (handle → DID → PDS),
  записи (like/repost/follow/…), завантаження і стиснення зображень, facets, фіди в налаштуваннях
- `js/ui.js` — рендер постів, ембедів, rich text, акторів; модалки, меню, тости, lightbox, HLS-відео, нескінченне прокручування
- `js/compose.js` — редактор постів (гілка з кількох постів, фото + ALT, картки посилань через cardyb, цитати, відповіді, мова,
  підказки @згадок, попередження про вміст, чернетка тексту в `skybee.draft`)
- `js/views.js` — екрани: головна, фід, список, гілка, профіль, сповіщення, пошук, фіди, закладки, чати, налаштування
- `js/more.js` — екрани: списки (створення, учасники, модераційні), стартові набори, фільтри контенту, акаунт, паролі застосунків; права колонка
- `js/settings.js` — налаштування: головний список розділів і всі підсторінки (`#/settings/<розділ>`); тема, шрифт, «спокійний» режим (`applyLook`).
  Нічого не відкриває на bsky.app — усе робиться в Skybee
- `js/flair.js` — «оформлення» профілю, яке бачать лише користувачі Skybee: статус у бульбашці біля аватарки, трек під біо
  (кнопка «+»: пошук по каталогу iTunes без ключа, з 30-секундним уривком; або посилання — дані через song.link),
  колір усієї сторінки (палітра `PALETTE`; CSS `body.sb-tint` + `--sb`: на світлій темі сам колір, на темній і в сутінках — його глибокий темний відтінок), іграшка-фото на банері. Зберігається в репозиторії користувача одним записом
  `io.github.vysocavnu.skybee.profile/self`; чужі читаються напряму з їхнього PDS без авторизації. Поля чужих записів перевіряються (`clean`)
- `js/notify.js` — системні сповіщення, поки застосунок відкритий (опитування раз на хвилину)
- `desktop/` — оболонка Electron: `main.js` (вікно, схема `app://skybee/` для вебфайлів, зовнішні посилання → системний браузер,
  один екземпляр, контекстне меню, самооновлення вебчастини: `updateWeb` обходить `index.html` → css/js → імпорти), `package.json` (налаштування electron-builder). `scripts/dist.mjs` копіює вебфайли в `desktop/web/`
  (новий файл/теку в корені треба дописати туди). Локально: `cd desktop && npm install && npm start`
- `js/app.js` — роутер на hash (`#/profile/<handle>/post/<rkey>` тощо), навігація, глобальні дії через `data-act`

## Правила
- Без фреймворків і без кроку збірки, поки ми на вебі.
- Інтерфейс — українською.
- Вхід: короткий нік (`@lejk309` → `lejk309.bsky.social`) або email. За замовчуванням **пароль застосунку**;
  основний пароль — лише за явним вибором користувача (з кодом із пошти, якщо ввімкнено 2FA).
- Чати йдуть через проксі-заголовок `atproto-proxy: did:web:api.bsky.chat#bsky_chat`.
- Перед комітом: `for f in js/*.js; do node --check --input-type=module < $f; done`

## Ще не зроблено
**Наступна версія десктопа (попросив автор, робити разом із наступним релізом оболонки):** застосунок при кожному запуску сам шукає
оновлення самого себе (оболонки), завантажує й ставить його зсередини, без переходу на GitHub — `electron-updater` + GitHub Releases
(для цього electron-builder має публікувати `latest.yml` у реліз).
Оплата за іграшку (потрібен платіжний сервіс і сервер, що підписує право на неї), вхід в акаунт стрімінгу й автоматичне «зараз грає» (потрібен зареєстрований застосунок Spotify/Last.fm з Client ID),
Справжні push-сповіщення при закритому застосунку (потрібен сервер), пошук GIF (потрібен ключ Tenor),
перегляд без входу, реєстрація в застосунку, сторонні сервіси модерації (labelers), налаштування сповіщень,
створення стартових наборів і фідів, «показувати більше/менше такого» у фідах.
